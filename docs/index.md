# Paged Again Challenges

> A collection of deterministic, real-world production incidents.

Welcome to the public runbook catalogue for [Paged Again](https://pagedagain.com/?utm_source=challenges&utm_medium=writeup&utm_campaign=home).

These are practical troubleshooting scenarios based on real outages, written for **Site Reliability Engineers (SREs), DevOps, and backend engineers**. Each page has the scenario, diagnostic steps, and root-cause write-up. Use the navigation to open a challenge; try it in the [live sandbox](https://pagedagain.com/incidents?utm_source=challenges&utm_medium=writeup&utm_campaign=catalog) before you unfold the solution.
